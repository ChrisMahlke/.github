# Defaults for my public app repositories

GitHub reads this repository for community health files that my other public repositories don't define themselves. Today that is the set of issue templates in `.github/ISSUE_TEMPLATE`: every public app repository (LOC IQ, Meridian, Opisometer, Mot Juste, Mahjong) gets the same "Report a problem", "Suggest something", and "Ask a question" forms unless it ships its own.

To tailor the forms for one app, copy `.github/ISSUE_TEMPLATE` into that app's public repository and edit the copy there. It then takes precedence over these.
